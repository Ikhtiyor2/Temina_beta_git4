# Промпт: создать сайт как TeminaFit

Скопируй текст ниже и используй как полное ТЗ для создания похожего фитнес-сайта с ИИ-тренером.

---

## Задача

Создай веб-приложение — **фитнес-платформу с ИИ-тренером и геймификацией**, по аналогии с TeminaFit.

### Концепция

- Пользователь выполняет упражнения перед камерой (ноутбук/телефон).
- В реальном времени система распознаёт позу (MediaPipe Pose), считает повторения (или секунды для планки), анализирует технику и выдаёт подсказки: «что не так» и «как исправить».
- Есть игровые элементы: уровни, опыт (XP), квесты, прокачка навыков (сила, выносливость, ловкость, техника), валюта, серия входов (streak), лидерборд.
- Дополнительно: конструктор тренировок (диалог: настроение → травмы → уставшие мышцы → план упражнений с повторениями).

### Стек (референс)

- **Backend:** Django (Python 3.10+), SQLite или PostgreSQL.
- **Frontend:** серверный рендеринг (Django templates), HTML/CSS/JS. Один базовый шаблон (header, sidebar для авторизованных, footer), блоки для страниц.
- **Распознавание поз:** в браузере — MediaPipe Pose (CDN: `@mediapipe/pose`, `@mediapipe/camera_utils`, `@mediapipe/drawing_utils`). Получаем 33 ключевые точки (landmarks) с кадра. Опционально: отправка landmarks на сервер, сервер считает повторения и возвращает count, feedback, errors (формат ниже).
- **Стиль:** тёмная тема (фон #0D0D10), градиент акцентов (#A855F7 → #D946EF), карточки с полупрозрачным фоном и тонкой рамкой, скругления 12–20px, шрифт Outfit. Адаптивная вёрстка, нижняя или боковая навигация на мобильных.

### Страницы и разделы

1. **Публичные:** главная, вход, регистрация, приветствие после входа.
2. **После входа:** дашборд (сводка: уровень, XP, серия, недавние тренировки), профиль (уровень, навыки, валюта, достижения), список тренировок (карточки упражнений с кнопкой «Начать»), квесты (список с прогрессом и наградами), статистика (тренировки, повторения, калории, по дням/неделям), лидерборд, настройки.
3. **Тренировка:** одна страница на все типы упражнений (параметр: pushups / squats / crunches / planks / pullups). Экран: камера (video + canvas), крупный счётчик повторений (или секунд для планки), таймер длительности, блок подсказок ИИ (feedback + список errors: «что не так» / «как исправить»), кнопки «Пауза» и «Сохранить».
4. **Конструктор тренировки:** пошаговый диалог (вопросы про настроение, травмы, уставшие мышцы), в конце — план: список упражнений с ссылками и рекомендуемыми повторениями.

### Упражнения и ИИ

- Типы: отжимания (PUSHUP), приседания (SQUAT), скручивания (CRUNCH), планка (PLANK), подтягивания (PULLUP).
- В браузере: MediaPipe даёт 33 landmarks (x, y, z, visibility, нормализованные 0–1). Логика подсчёта на клиенте или на сервере.
- Формат подсказок: массив `errors`, каждый элемент: `{ "message": "что не так", "hint": "как исправить", "priority": 1 или 2 }`. Плюс одна строка `feedback` (общий статус). Не показывать больше 2–4 ошибок за раз, сортировать по priority.
- Для отжиманий: углы в локтях, подтверждение фаз (2 кадра вниз / вверх), проверки: руки на полу, локти не разводить, задержка в нижней точке, линия корпуса. Для приседаний: угол в коленях, глубина приседа, колени не за носки. Для планки: секунды в правильной позе, линия плечи–таз–лодыжки. Аналогично описать логику для скручиваний и подтягиваний или взять референс из open-source (MediaPipe + правила по углам).

### API (если есть backend)

- **POST** `/api/ai/process-landmarks/` — тело: `{ "exercise_type": "PUSHUP"|"SQUAT"|..., "landmarks": [ { "x", "y", "z", "visibility" }, ... ] }`. Ответ: `{ "success": true, "count": int, "stage": "up"|"down", "ready": bool, "feedback": string, "errors": [ { "message", "hint", "priority" } ] }`.
- **POST** `/api/workouts/start/` — `{ "exercise_type": "..." }`.
- **POST** `/api/workouts/complete/` — `{ "exercise_type", "count", "duration_seconds", "errors_count", ... }` — сохранить подход, обновить квесты и статистику.
- **GET** `/api/quests/`, **POST** `/api/quests/start/`, **POST** `/api/quests/complete/`.
- **GET** `/api/stats/...`, **GET** `/api/player/profile/`, **POST** `/api/player/upgrade-skill/`.
- **POST** `/api/workout-builder/chat/` — диалог конструктора (state, answer) → следующий вопрос или план.

### Модели данных (референс)

- User (Django), Player (OneToOne: level, exp, skill_points, strength, stamina, agility, technique, currency, fatigue, login_streak).
- Quest (player, title, description, quest_type, goal, progress, reward_xp, reward_currency, completed, expires_at и т.д.).
- WorkoutSession / WorkoutSet (player, exercise_type, reps_count, duration_seconds, date).
- PlayerStats (total_workouts, total_reps, total_calories, current_streak, max_streak, разбивка по упражнениям, рекорды).
- ActiveWorkout (текущая тренировка в реальном времени: count, stage, ready, frame_data для хранения состояния между запросами landmarks).

### Дизайн и UX

- Тёмная тема: фон #0D0D10, карточки rgba(255,255,255,0.04), граница rgba(255,255,255,0.08).
- Акценты: градиент #A855F7 → #D946EF для кнопок и заголовков; зелёный для успеха, оранжевый/красный для предупреждений.
- Шрифт: Outfit (Google Fonts). Иконки: Remix Icon (CDN).
- Шапка: логотип, навигация (Главная, Тренировки, Дашборд, Статистика, Квесты, Профиль), переключатель языка (EN/RU), кнопка Войти/Выйти.
- Для авторизованных: боковая панель (иконки: главная, тренировки, квесты, лидерборд, статистика, профиль, выход).
- Футер: блок «Упражнения» (ссылки на все типы тренировок), блок «Аккаунт» (Вход, Регистрация), копирайт. Все ссылки рабочие.
- Два языка: русский и английский. Переключение по кнопке EN/RU, сохранение выбора в cookie, в шаблонах вывод текста в зависимости от текущего языка.

### Дополнительно

- PWA: manifest.json (name, short_name, start_url, display: standalone, theme_color, icons), service worker для кэширования статики, возможность «Установить приложение».
- На странице тренировки: сначала показать видео с камеры (getUserMedia), затем в фоне инициализировать MediaPipe Pose; при повторном заходе в той же вкладке переиспользовать уже созданный Pose для быстрого старта.
- Счётчик повторений и подсказки ИИ должны работать стабильно: те же пороги углов и те же тексты ошибок, что и в референсе (отжимания, приседы, планка и т.д.).

### Критерии готовности

- Регистрация и вход работают.
- Есть дашборд, профиль (уровень, навыки, валюта), список тренировок, квесты, статистика, лидерборд.
- При выборе упражнения открывается экран с камерой; отображаются счётчик повторений (или секунды для планки) и подсказки ИИ (feedback + errors с message и hint).
- После тренировки можно сохранить результат; сохраняется подход, обновляются квесты и статистика.
- Квесты показывают прогресс и награды; при достижении цели квест завершается, начисляются XP/валюта/скилл-поинты.
- Конструктор тренировки ведёт диалог и выдаёт план с упражнениями и повторениями.
- Интерфейс на двух языках (RU/EN), футер с рабочими ссылками на упражнения и аккаунт.
- Внешний вид: тёмная тема, градиентные акценты, карточки, как в описании выше.

Используй этот документ как полное ТЗ для создания сайта уровня TeminaFit: фитнес с ИИ по камере, геймификация, квесты, статистика, два языка и аккуратный современный интерфейс.
