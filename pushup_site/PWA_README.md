# TeminaFit — установка как приложение (PWA)

Сайт TeminaFit теперь поддерживает **Progressive Web App (PWA)**. Его можно установить на телефон или компьютер и открывать как обычное приложение.

## Что сделано

- **Манифест** (`/static/manifest.json`) — название, иконка, цвет темы, режим `standalone`.
- **Иконка** (`/static/icons/icon.svg`) — логотип в стиле TeminaFit для экрана «Домой».
- **Сервис-воркер** (`/sw.js`) — кэширование статики для быстрой загрузки и работы при слабом интернете.
- В **base.html** добавлены ссылка на манифест, мета-теги для iOS и регистрация сервис-воркера.

## Как установить

### На телефоне (Android / iPhone)

1. Откройте сайт в **Chrome** (Android) или **Safari** (iPhone):  
   `https://temina.fit` или ваш адрес.
2. **Android (Chrome):** меню (⋮) → «Установить приложение» / «Добавить на главный экран».
3. **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“» → «Добавить».

После этого иконка TeminaFit появится на главном экране; при запуске откроется полноэкранный режим без адресной строки.

### На компьютере (Chrome / Edge)

1. Откройте сайт в Chrome или Edge.
2. В адресной строке справа появится значок установки (⊕ или «Установить»).
3. Нажмите «Установить» — приложение добавится в меню Пуск / приложения.

## Проверка

- Убедитесь, что по адресу `/sw.js` отдаётся JavaScript (страница с кодом сервис-воркера).
- В Chrome: DevTools → Application → Manifest — манифест должен подтянуться без ошибок.
- Application → Service Workers — сервис-воркер должен быть в статусе «activated».

## Дополнительно

- Иконки 192×192 и 512×512 в PNG можно добавить в `static/icons/` и прописать в `manifest.json` для лучшей поддержки на всех устройствах.
- Для публикации в магазинах приложений (Google Play / App Store) по ТЗ нужен отдельный проект (React Native, Flutter или TWA/Capacitor); текущий PWA даёт установку через браузер без магазинов.
