# Два языка интерфейса (русский и английский)

## Где переключить язык

Переключатель **EN | RU** есть в двух местах:

1. **Шапка сайта** (справа, рядом с кнопкой «Войти» / «Выйти») — виден **гостям** и на мобильной версии.
2. **Боковая панель** (внизу, над кнопкой «Выйти») — виден **авторизованным** пользователям, когда открыта боковая панель.

Нажатие на **EN** или **RU** сохраняет выбор в cookie и перезагружает страницу — весь интерфейс из базового шаблона (меню, футер, кнопки) показывается на выбранном языке.

## Что уже переведено

В **base.html** на двух языках выводятся:

- Подпись под логотипом (Фитнес с ИИ / AI Fitness).
- Вся навигация: Главная, Тренировки, Панель, Статистика, Лидерборд, Квесты, Профиль.
- Кнопки: Войти, Выйти, Регистрация, Онлайн.
- Мобильное меню (все пункты и подсказки).
- Футер: описание, блок «Упражнения», блок «Аккаунт», копирайт.

Контент **внутренних страниц** (главная, дашборд, тренировки, квесты, профиль и т.д.) пока в основном на русском. Чтобы перевести их:

## Как добавить перевод на странице

1. Открой нужный шаблон (например `main/home.html`, `main/workouts.html`).
2. В шаблон уже передаётся переменная **`current_lang`** (`'ru'` или `'en'`).
3. Оборачивай текст в условие:

```django
{% if current_lang == 'en' %}English text{% else %}Русский текст{% endif %}
```

Пример для заголовка:

```django
<h1>{% if current_lang == 'en' %}Workouts{% else %}Тренировки{% endif %}</h1>
```

После сохранения шаблона при выборе EN в переключателе будет показываться английский вариант.

## Где в коде настроена логика языка

- **Контекст:** `main/context_processors.py` — добавляет `current_lang` из cookie `temina_lang`.
- **Переключение:** view `set_language_view` в `main/views/page_views.py`, URL `set-language/?lang=en` или `?lang=ru`.
- **Шаблон:** все строки с двумя языками в `main/templates/base.html` (навигация, футер, переключатель).

Язык по умолчанию — русский (если в cookie ничего нет).
