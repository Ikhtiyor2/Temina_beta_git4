Логотип TeminaFit
================
1. Положи сюда свой файл логотипа (PNG без фона).
2. Назови файл строго:  logo.png
3. Если уже был logo.png — замени его полностью (удали старый, скопируй новый).
4. Открой приветственную страницу и нажми Ctrl+Shift+R (жёсткое обновление без кэша).
